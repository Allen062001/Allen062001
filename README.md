## 📱 TAGA-CUYO

### Tagalog–Cuyonon Translator & Spoken Language Query System

TAGA-CUYO is a mobile application developed to help preserve, promote, and introduce the **Cuyonon language and culture** through technology.

### Features

- 🇵🇭 Tagalog–Cuyonon translation
- 🔊 Audio pronunciation
- 📷 Image-to-text translation
- 📚 Interactive language lessons
- 🧠 Translation quizzes
- 📊 Learning progress tracking
- 📅 Learning activity calendar
- 🏝️ Cuyo festivals and cultural information
- 💬 User feedback and complaints
- 👤 User profile management

### Technologies

`Flutter` `Dart` `Firebase Authentication` `Cloud Firestore` `Firebase Hosting` `Google Cloud`
